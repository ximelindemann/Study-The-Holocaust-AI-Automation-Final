# Exports técnicos de n8n

Esta carpeta contiene los exports JSON de los workflows usados en el ecosistema de automatización.

## Workflows incluidos

- Agente educativo con OpenAI, RAG y registro en Airtable.
- Flujo Human-in-the-loop para validación humana por Gmail.
- Flujo de indexación de contenido del sitio hacia Supabase.

Estos archivos sirven como respaldo técnico para revisar la implementación en n8n.
